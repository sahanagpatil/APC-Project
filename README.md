# Arbitrary Precision Calculator (APC)

## Description

This project performs arithmetic operations on very large integers using a doubly linked list.

## Operations

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Files

- main.c
- apc.h
- dll.c
- compare.c
- check_sign.c
- addition.c
- subtraction.c
- multiplication.c
- division.c
- Makefile

## Compilation

```bash
make

Execution
./a.out operand1 operator operand2
